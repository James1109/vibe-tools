# vibe-tools
Vibe Coding 出來的小工具

## 一、 專案基本資料
* **專案名稱**：台灣氣象生活儀表板 (Taiwan Weather Life Dashboard)
* **核心目標**：以互動式台灣地圖為核心介面，讓使用者透過點擊不同縣市，即時獲取該區域的氣象數據、24 小時溫度與降雨趨勢，並結合動態計算的「生活指數」，協助使用者進行日常出行與生活決策。
* **目標使用者**：台灣在地居民、通勤族、戶外運動者及計畫於全台各地出行的使用者。

---

## 二、 核心功能與互動機制

### 1. 全台互動地圖 (Interactive SVG Map)
* **地圖呈現**：透過 D3.js 與 TopoJSON 載入內政部行政區界 (taiwan-atlas) 繪製 SVG 地圖；若網路 API 或外套件載入失敗，具備備用手繪簡化版地圖 (Fallback) 的容錯機制，確保網頁無縫顯示。
* **懸浮與點擊互動**：滑鼠懸浮縣市會高亮變色，點擊縣市後即時載入該縣市氣象資料；支援鍵盤 Enter 鍵選取，具備無障礙（Accessibility）設計。
* **當前縣市高亮**：地圖上會持續以特定色彩標示目前選取區域。

### 2. 即時氣象資訊看板 (Current Weather Panel)
* **即時數據**：顯示當前縣市名稱、天氣狀況圖示與描述（如☀️晴朗、🌧下雨）、目前氣溫、體感溫度、相對濕度、風速、降雨機率與紫外線指數。
* **資料來源標籤**：動態標示資料來源（如：Open-Meteo 即時資料 或 模擬備用資料）。

### 3. 智慧生活指數系統 (Life & Activity Index)
根據氣溫、濕度、風速及未來 24 小時降雨率與紫外線數據，透過演算法動態計算四大生活指標：
* **👕 曬衣服指數**：綜合評估降雨率、濕度、紫外線與風速，給予「適合 / 普通 / 不宜」建議與評分。
* **🏃 戶外運動指數**：評估體感溫度、紫外線與降雨率，提醒是否做好防曬或改為室內運動。
* **🚗 洗車指數**：根據未來 24 小時最高降雨機率判斷是否適合洗車。
* **☂️ 帶傘提醒**：依據未來 12 小時最高降雨機率發出提醒（務必帶傘 / 建議帶傘 / 不需帶傘）。

### 4. 24 小時預報趨勢圖 (Hourly Forecast Chart)
* 運用 Chart.js 繪製雙 Y 軸混合圖表：
  * **折線圖**：呈現未來 24 小時溫度變化曲線。
  * **長條圖**：呈現未來 24 小時降雨機率百分比。
* 隨著使用者切換縣市，圖表會動態銷毀（destroy）並重新繪製對應數據。

### 5. 使用者體驗與介面 (UX & Interface)
* **深色 / 淺色模式切換**：可一鍵切換深淺色主題，且系統會自動偵測使用者裝置的系統偏好（prefers-color-scheme）作為初始設定。
* **現代玻璃擬物化 (Glassmorphism) 設計**：採用半透明毛玻璃質感卡片、動態漸層背景與平滑過渡動畫。
* **響應式佈局 (RWD)**：支援桌面雙欄與行動裝置單欄直向排列。

## 三、 技術架構與資料來源

* **檔案結構**：單一檔案 index.html（CSS 寫於 <style>，JS 寫於 <script>）。
* **前端框架與套件 (CDN)**：
  * **D3.js & TopoJSON**：用於繪製高精度 SVG 行政區界地圖。
  * **Chart.js**：用於渲染動態氣象圖表。
* **氣象 API 來源**：
  * 使用 **Open-Meteo API**（免 API Key，可直接經緯度查詢）獲取即時與 24 小時逐時氣象預報數據。
  * **Mock 備用機制**：若 Open-Meteo API 請求失敗或網路中斷，網頁會自動調用內建算式生成擬真模擬數據，確保整體網頁功能依然可順暢操作展示。
